# Karoowa Documentation

End-user-facing documentation for Karoowa v1.0. Engineering specs live in `specs/`; this directory is the reading path for people running or building on a Karoowa node.

## Table of Contents

| Doc | Audience | Read when |
|---|---|---|
| [Operator Guide](operator-guide.md) | Ops engineers | You're about to run a node (validator, full node, or light) |
| [Developer Guide](developer-guide.md) | App developers | You're building contracts, dApps, agents, or SDK consumers |
| [Tokenomics](tokenomics.md) | Validators, delegators, token holders | You want to understand KAR supply, fees, rewards, treasury |
